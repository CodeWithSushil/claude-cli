## Claude Code CLI for PHP

It is **Claude Code** CLI run on your terminal.

---

### Install & Setup

```bash
composer global require sushilk/claude-cli
```

* you already install but you want to update to latest version so just do this:

```bash
composer global update sushilk/claude-cli
```

* create config file:

`$ ~/.config/claude/config.json`
